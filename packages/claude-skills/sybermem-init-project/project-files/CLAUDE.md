## SyberMem Session Protocol

1. Read `.sybermem/INDEX.md` `## Key Conclusions` at session start.
2. If important work is happening, prefer `/sybermem-record`.
3. If unsure what to do next, run `/using-sybermem`.

Detailed behavior is defined in each skill's SKILL.md.
<!-- SYBERMEM_SESSION_PROTOCOL:END -->

## Core Rule

After completing meaningful work, run `/sybermem-record` to create a record.

## Directories

- `.sybermem/changes/` — Feature changes
- `.sybermem/decisions/` — Technical decisions
- `.sybermem/requirements/` — Requirements / discussions
- `.sybermem/bugs/` — Bug fixes
- `.sybermem/INDEX.md` — Master index

## No Record Needed

Formatting adjustments, comment edits, config tweaks with no functional impact.
