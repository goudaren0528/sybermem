# monthly-summary Skill

生成本月进展月报，汇总本月工作和里程碑，**深度提炼开发者偏好和价值观**。

## 使用方式
- 用户执行 `/monthly-summary`
- 定时触发（每月结束）

## 核心设计

**深度提炼：** 基于一个月的开发数据，更准确地提炼偏好和价值观，更新 developer/preferences.md 和 developer/values.md。

月度提炼比周度更准确，因为样本更多、模式更明显。

## 流程

### Step 1: 读取 PROGRESS.md
获取本月进展信息

### Step 2: 读取本月创建的记录
扫描本月所有记录：
- ADR/decisions/
- CHANGELOG/
- EXPERIENCES/
- SPECIAL-CASES/

### Step 3: 汇总本月成果
- 功能交付情况
- 重要里程碑
- 经验沉淀
- 数据统计

### Step 4: 深度分析并提炼开发者偏好（新增）

**月度深度分析：**

| 分析维度 | 数据来源 | 提取内容 |
|----------|----------|----------|
| 技术选型趋势 | 本月所有 ADR | 技术栈偏好、选型标准 |
| 编码模式统计 | CHANGELOG + commit | 常用模式、风格偏好 |
| 问题处理习惯 | EXPERIENCES | 调试方法、问题分类 |
| 决策风格 | ADR 方案选择 | 风格偏好（保守/激进/平衡） |
| 价值观表达 | 对话 + 决策理由 | 核心价值观 |

**深度提炼逻辑：**
```
# 统计本月技术选型
if (本月 ADR 中 TypeScript 选择占比 > 70%):
  preferences.技术栈偏好 = "TypeScript 优先"
  confidence = "高（本月 70%+ 选择）"

# 统计决策风格
if (本月 ADR 中保守方案选择占比 > 60%):
  values.决策风格 = "倾向稳妥方案"
  evidence = "本月 8 个 ADR 中 5 个选择保守方案"

# 统计开发习惯
if (本月 TDD 实践次数 > 10):
  preferences.开发习惯 += "测试驱动开发（高频实践）"
```

### Step 5: 更新 developer/preferences.md 和 developer/values.md（新增）

**月度更新策略：**
- 统计验证：基于数据统计，标注置信度
- 合并去重：合并周度提炼内容，去重复
- 证据支撑：每条偏好标注来源证据

```markdown
## 开发偏好（月度提炼于 2026-05）

### 技术栈偏好
- TypeScript 优先（本月 ADR 中 75% 选择 TS，置信度：高）
- 函数式编程风格（本月 80% 新代码使用函数式写法）

### 开发习惯
- 测试驱动开发（本月 15 次 TDD 实践，置信度：高）
- 小步提交（本月平均每次 commit 改动 2-3 个文件）

### 工具偏好
- VSCode + Claude Code（本月 95% 时间使用）

---
## 开发价值观（月度提炼于 2026-05）

### 代码质量观
- 可读性优先（本月 ADR-003 明确表达）
- 简洁优于复杂（本月重构决策 3 次倾向简化）

### 效率观
- 优先解决实际问题（本月 Bug 修复优先级高于重构）

### 决策风格
- 倾向稳妥方案（本月 8 个 ADR 中 5 个选择保守方案）
- 重视可维护性（本月多次强调可维护性）

### 来源统计
- 本月 ADR：12 条
- 本月 CHANGELOG：25 条
- 本月 EXPERIENCES：8 条
```

### Step 6: 生成月报内容
动态生成月报（不持久存储）

### Step 7: 输出月报和偏好更新
显示给用户：
- 本月月报
- 深度提炼的偏好和价值观（带置信度）
- 来源证据统计

## 月报格式
```markdown
# 本月进展月报（YYYY-MM）

## 功能交付情况
- 新增功能：xxx

## 重要里程碑
- 完成架构重构

## 经验沉淀
- 踩坑经验：xx条

## 数据统计
- 新增 ADR：xx条
- 新增 CHANGELOG：xx条

## 偏好提炼（置信度：高）
- 技术栈：TypeScript 优先
- 开发习惯：测试驱动开发

## 下月计划
```

## 与周度提炼的关系

| 维度 | 周度提炼 | 月度提炼 |
|------|----------|----------|
| 数据量 | 本周数据 | 本月数据（更全面） |
| 置信度 | 初步发现 | 统计验证（更高） |
| 更新方式 | 增量追加 | 合并去重 + 置信度标注 |
| 证据 | 单次观察 | 多次统计 |

月度提炼会整合本周所有周度提炼内容，基于更大样本验证和标注置信度。
